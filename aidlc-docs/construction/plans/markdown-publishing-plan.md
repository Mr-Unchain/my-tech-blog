## 契約

- `src/content/blog/*.md`: 公開リポジトリに載せる記事。
- `src/content/drafts/*.md`: `.gitignore` と `.vercelignore` で除外するローカル下書き。開発サーバーのみで読む。
- `draft: true` の記事は通常の一覧・RSS・サイトマップ・検索・ブックマークに出さない。本番の詳細 URL でも返さない。
- Git に一度コミットした内容は履歴にも残る。下書きフラグを機密保護とは説明しない。
- プロフィール・プロジェクトの microCMS 利用と既存 Firebase ID は維持する。
- 記事の正本切替後に microCMS の削除操作で Firebase 情報を消さないよう、旧同期エンドポイントを停止する。
