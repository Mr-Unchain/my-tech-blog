# 執筆環境 要件確認質問

この AI-DLC ワークフローでは、スマートフォンと PC のどちらからでも記事を書きやすいブログ執筆環境を検討します。各質問の `[Answer]:` の後ろに、該当する選択肢の記号を入力してください。どの選択肢も合わない場合は `X` を選び、希望内容を `[Answer]:` の後ろに追記してください。

## Question 1
新しい執筆環境で一番重視したい成果はどれですか？

A) microCMS をコンテンツの正本として維持しつつ、周辺の執筆 UI を改善する
B) 記事執筆をこのリポジトリ内の Markdown / MDX ファイルへ移し、Git ベースで公開する
C) より書きやすい別のヘッドレス CMS に移行する
D) このブログ内に独自の管理画面 / エディタを作る
X) その他（`[Answer]:` の後ろに内容を書いてください）

[Answer]:本当はGitベースで執筆するのが楽な気はしますが、いちいちデプロイするのがイケてない気がします。どれがいいでしょうかね。。。

## Question 2

C) スマートフォンと PC の両方で同じくらい書きやすくする

## Question 3

C) Notion / WordPress Gutenberg のようなブロックエディタ

X) その他（`[Answer]:` の後ろに内容を書いてください）

[Answer]:一番良いのはブログの公開後のプレビューを見ながら執筆できる環境ですが、ObsidianもVSCODEも使っているので、AかDがいいですね。

## Question 4

D) 当面は手動デプロイでも許容する
