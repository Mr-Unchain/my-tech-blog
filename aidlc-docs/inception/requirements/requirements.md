# Requirements Document

## Intent Analysis Summary

- **User Request**: 「プロダクトを改善したい」— Zenn.dev を参考にした大規模 UI/UX 改善 + 全技術的負債の解消
- **Request Type**: Enhancement（既存プロダクトの改善）
- **Scope Estimate**: System-wide（システム全体に影響する変更）
- **Complexity Estimate**: Complex（UI/UX全面改修 + 技術的負債 + Zennインスパイアの新デザインパターン）
- **Reference Site**: zenn.dev（日本最大級のエンジニア向けコンテンツプラットフォーム）
- **Constraints**: なし（デザインテーマ変更も含め全面改善可）
- **Infrastructure**: 変更なし（Vercel + Firebase + microCMS 継続）

---

## Functional Requirements

### FR-1: Zennインスパイアのレイアウト再設計

#### FR-1.1: ライト/ダークテーマ切替
- **現状**: ダークテーマ固定
- **目標**: Zennのようにシステムテーマ自動検出 + ユーザー手動切替を実装
- **詳細**:
  - `prefers-color-scheme` メディアクエリによる自動検出
  - ヘッダーにテーマ切替トグルを配置
  - 選択をlocalStorageに永続化
  - Tailwind CSS のダークモード機能を活用

#### FR-1.2: クリーンなレイアウト構成
- **現状**: サイドバー付きの複雑なグリッドレイアウト
- **目標**: Zennのようなセンター配置のシンプルなレイアウト
- **詳細**:
  - ホームページ: 記事リスト中心のシンプルな構成
  - 記事詳細: 本文中心 + 目次サイドバー（PC）の2カラム
  - 不要なビジュアル要素の削減（過度なグラデーション、グロー効果等）

#### FR-1.3: ナビゲーション改善
- **現状**: ヘッダーのリンクメニュー
- **目標**: Zennのような「Trending」「Latest」「カテゴリ」のタブナビゲーション
- **詳細**:
  - ホームページにタブ形式のフィルター（最新/人気/カテゴリ）
  - タブ切り替え時の滑らかなトランジション

### FR-2: 記事カードの再設計

#### FR-2.1: Zenn風カードデザイン
- **現状**: サムネイル重視の大きなカード
- **目標**: Zennのようなコンパクトで情報密度の高いカード
- **詳細**:
  - 絵文字またはサムネイルによるコンテンツ識別
  - タイトル + 著者 + メタ情報（日付、リアクション数）のコンパクト表示
  - ホバー時の繊細なインタラクション

#### FR-2.2: メタ情報の充実
- **現状**: 日付とカテゴリのみ
- **目標**: リアクション数、閲覧数、コメント数をカードに表示
- **詳細**:
  - Firebase から統計データを取得してカードに表示
  - アイコン付きの小さなカウンター表示

### FR-3: 記事詳細ページの改善

#### FR-3.1: 記事本文の読みやすさ向上
- **現状**: Zenn風のフォントサイズ調整済みだが改善余地あり
- **目標**: Zennレベルの読みやすいタイポグラフィ
- **詳細**:
  - 適切な行間（1.8〜2.0）
  - 見出し間の余白最適化
  - コードブロックの視認性向上
  - 画像のキャプション対応

#### FR-3.2: 目次のUX改善
- **現状**: React Island によるスクロール連動目次
- **目標**: 更に使いやすい目次体験
- **詳細**:
  - 目次の折りたたみ/展開（モバイル）
  - 現在位置のプログレス表示
  - スムーズスクロール

#### FR-3.3: リアクション/エンゲージメントUIの改善
- **現状**: 4種類のリアクションボタン（PC: 左サイドバー固定、モバイル: 記事末尾）
- **目標**: Zennのようなシンプルで直感的なリアクションUI
- **詳細**:
  - リアクションのアニメーション強化
  - 記事末尾のエンゲージメントセクション統合（リアクション + シェア + ブックマーク）

### FR-4: ブックマーク機能の完成

#### FR-4.1: ブックマークAPI実装
- **現状**: 型定義・コレクション名のみ存在（プレースホルダー）
- **目標**: 完全なブックマーク機能
- **詳細**:
  - GET: ブックマーク状態取得
  - POST: ブックマーク追加/削除（トグル）
  - ブックマーク一覧ページ

#### FR-4.2: ブックマークUI
- **詳細**:
  - 記事カード・記事詳細にブックマークアイコン
  - ブックマーク済み状態の視覚的フィードバック
  - ブックマーク一覧ページ（`/bookmarks`）

### FR-5: 検索機能の強化

#### FR-5.1: 検索UXの改善
- **現状**: 基本的なクライアントサイド検索
- **目標**: 即座にフィードバックのある検索体験
- **詳細**:
  - インクリメンタルサーチ（入力中にリアルタイム結果表示）
  - 検索結果のハイライト表示
  - 「結果なし」時の改善提案

### FR-6: ヒーローセクションの再設計

#### FR-6.1: ホームページファーストビュー
- **現状**: 大きなヒーロー + スライドショー + 検索 + カテゴリチップ
- **目標**: Zennのようなシンプルで洗練されたファーストビュー
- **詳細**:
  - コンテンツ中心の設計（記事リストへの素早いアクセス）
  - 過度な装飾の削減
  - 検索バーの目立つ配置

## Non-Functional Requirements

### NFR-1: パフォーマンス
- Core Web Vitals のスコア維持・改善（LCP < 2.5s, FID < 100ms, CLS < 0.1）
- テーマ切替時のFOUC（Flash of Unstyled Content）防止
- React Islands の遅延ロード最適化

### NFR-2: アクセシビリティ
- WCAG 2.1 AA 準拠
- ライト/ダーク両テーマでのコントラスト比確保
- キーボードナビゲーション対応の維持・強化
- スクリーンリーダー対応の維持

### NFR-3: SEO
- 既存の構造化データ・OGP・canonical URL 等の維持
- ページ速度改善によるSEOスコア向上

### NFR-4: レスポンシブデザイン
- モバイルファースト設計
- ブレークポイント: sm(640px), md(768px), lg(1024px), xl(1280px)
- タッチフレンドリーなインタラクション

### NFR-5: ブラウザ対応
- Chrome, Firefox, Safari, Edge の最新2バージョン
- iOS Safari, Android Chrome 対応

## Technical Requirements

### TR-1: 技術的負債の解消

#### TR-1.1: Firebase null チェック強化
- **対象**: src/pages/index.astro
- **内容**: `db` の null チェックを追加し、Firebase未設定時のクラッシュを防止

#### TR-1.2: Bookmarks API 完成
- **対象**: src/pages/api/bookmarks/[blogId].ts
- **内容**: GET/POST エンドポイントの実装 + Firestore トランザクション

#### TR-1.3: インラインスクリプトの分離
- **対象**: src/pages/index.astro, src/pages/blog/[id].astro
- **内容**: インラインスクリプトを独立モジュールに分離し、テスタビリティ・保守性を向上

#### TR-1.4: Webhook署名検証の必須化
- **対象**: src/pages/api/webhook/microcms-sync.ts
- **内容**: 本番環境では署名検証を必須化。未設定時はエラーログ + リクエスト拒否

### TR-2: Tailwind CSS ダークモード設定
- `tailwind.config.mjs` の `darkMode` を `'class'` に設定
- 全コンポーネントに `dark:` プレフィックスのスタイルを追加

### TR-3: テーマ管理ロジック
- テーマ切替のグローバル状態管理
- SSR対応（サーバーサイドでのテーマ判定なし、クライアントサイドで適用）
- FOUC防止のための `<script>` をhead内に配置

| 観点 | 現状（Monologger） | 目標（Zenn参考） |
|------|-------------------|-----------------|
| テーマ | ダーク固定 | ライト/ダーク切替 |

| 記事カード | サムネイル大 | コンパクト + メタ情報充実 |
| ナビゲーション | リンクメニュー | タブナビゲーション |
